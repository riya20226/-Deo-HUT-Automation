#  DEO HUT Automation Framework

This project is a Test Automation Framework built using Robot Framework and Selenium to automate testing for the DEO HUT application.

---

##  Tech Stack

- Python
- Robot Framework
- SeleniumLibrary
- Firefox (GeckoDriver)

---

##  Project Structure

DEO-HUT-AUTOMATION/

- pages/ → Page Object Model files  
- resources/ → Common keywords & variables  
- tests/ → Test cases  
- variables/ → Test data  
- logs/ → GeckoDriver logs  
- results/ → Reports & screenshots  
- README.md  
- requirements.txt
